# Как запустить сайт на Windows

## Шаг 1 — установить Node.js

Если Node.js ещё нет:
1. Откройте https://nodejs.org/
2. Скачайте LTS-версию.
3. Установите её обычным способом.
4. Перезагрузку обычно делать не требуется.

## Шаг 2 — вставить токен

1. Откройте файл `.env` в этой папке через Блокнот.
2. Найдите:

BOT_TOKEN=PASTE_NEW_BOT_TOKEN_HERE

3. После `=` вставьте НОВЫЙ токен Telegram-бота.
4. Строка `CHAT_ID=5286748762` уже настроена.
5. Сохраните файл.

## Шаг 3 — запустить

Дважды нажмите:

START.bat

Скрипт сам:
- проверит Node.js;
- установит зависимости;
- запустит сервер;
- откроет сайт в браузере.

## Шаг 4 — проверить Telegram

Заполните форму и нажмите «Отправить заявку».

Заявка должна прийти в Telegram.

## Если сайт нужно разместить в интернете

Сейчас этот проект запускается на вашем компьютере. Чтобы сайт принимал заявки, когда компьютер выключен, его нужно разместить на хостинге/VPS. Саму папку сайта можно использовать для этого без переделки логики.
